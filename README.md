# Blazor Basics

An intro-to-Blazor conference talk targeting .NET 10.

## Repository layout

- `docs/` — talk plan, demo project spec, and a reference summary of Blazor changes in .NET 9 and .NET 10.
- `slides/` — slide deck source (coming).
- `src/` — sample code (coming). A single Blazor Web App that hosts the same component under all four render modes (Static SSR, InteractiveServer, InteractiveWebAssembly, InteractiveAuto).
